# Doc drift fixes — design spec

**Baseline**: written against `main` at `341ceaa` (`v0.4.0` + `orphan-stop-warning` + `week-notes` + `export-notes` + `panic-fixes` + `relative-ids`, unreleased).
**Branch**: `doc-drift`, which already carries the MSRV fix (`9bc2266`: `rust-version = "1.95"`, README `1.95+`, one `collapsible_if` in `src/date.rs`).
**Status**: draft.
**Input**: the drift sweep `docs/dev/plans/reports/doc-drift-sweep-review.md`
(F1-F21). The user approved fixing F1-F20 on 2026-10-31. F21 is dropped.

## 1. Summary

The live docs and two `--help` strings have drifted from the shipped
code. After this changeset README, `--help`, SPEC.md, AGENTS.md,
NOTES.md's header and `docs/dev/README.md` state what the code does,
SPEC.md covers `delete` and backdated `TIME` on its own, and every
archived file carries its banner.

## 1.1 Non-goals

- No behavior change. The only output change is the two `--help`
  strings in §3.
- F21 (`mlm week 0999-05` names the week number, not the year) stays as
  it is.
- The numbered NOTES.md log stays as written, apart from the F4 pointer.

## 1.2 Known issues

None.

## 4. Internal fixes

- **F4**: SPEC.md gains the `delete note|punch` surface from the archived
  delete spec (`docs/dev/specs/2026-09-13-delete-punches-notes.md`

  and `docs/dev/plans/reports/` without a banner gets one, after its

  names reports as archived.

- **F17**: SPEC §6.1's read-failure list gains `status`'s note read and
  its lookback read.

  puts the exit-code mapping, `OutputError` and `emit` in `lib.rs`.

  `src/time.rs` dead-code note (and its `#![allow(dead_code)]` if
