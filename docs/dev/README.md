# Dev docs

Two live documents drive further development here:

- **[`NOTES.md`](NOTES.md)** — running design/process log: background, decisions, deferred/stretch scope. Informal by design; can change.
- **[`SPEC.md`](SPEC.md)** — the formal spec. Current behavior, built incrementally from `NOTES.md` decisions.

Everything else under `docs/dev/` (`PLAN.md`, `plans/`, `specs/`) is an
**archived historical record** of how past changesets were planned and
reviewed — useful for context on why something was built a certain way,
never authoritative on current behavior. Each archived file carries an
`Archived` banner pointing back here.
